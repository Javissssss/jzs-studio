# 公众号「巨人之上」文风与排版规范

## 定位与受众

- **频道名**：巨人之上
- **受众**：AI时代想借力提效的普通人（非开发者为主），关注AI工具、宏观财经、效率方法论
- **核心主张**：不自己造轮子，先去找别人造好的缆车。这个时代奖励最会借力的人。

## 文风铁律（正文 MD，2500-4000字）

| 维度 | 规则 |
|------|------|
| 开篇 | 直接切入事件或具体细节，不废话背景；或用两组数字、一张排期的反差在三句内抓人 |
| 叙述腔调 | 观察者口吻，不布道、不说教；像同事讲给同事听 |
| 长句拆短 | 一句话不超过30字；能断就断 |
| 比喻 | 用生活场景打比方（如"铺子收租"讲美债收益率，"缆车"讲借力习惯） |
| 数据落地 | 每个抽象观点都跟一个具体数字或例子 |
| 反直觉 | 专门设一小节讲"和常识不一样的地方" |
| 结尾 | 判断句收口 + 互动问句引导评论；不做摘要式收尾 |
| 框架 | 用一个一句话能说清的框架贯穿全文（如"四笔账"），开头一句宣告；H2用带判断或疑问的口语句 |
| 重点 | 每节核心判断句加粗，让读者只滑加粗也能拿走结论 |
| 来源交代 | 口语化交代来路（"我早前看过一次采访""有从业者算过自己的账"）；正文不出现官媒署名、不用[1]式脚注 |
| 禁止 | 冒号排比、"不是A而是B"句式、营销腔、"论点01"式标签、官媒官腔、法规公文名 |

## 结构模板

1. 引子（直接切入事件/现象，不废话背景）
2. 核心机制讲清楚（1-2节，用生活比喻）
3. 结合当前案例展开（1-2节）
4. 反直觉或延伸观察（1节）
5. 接下来怎么看 / 能马上执行的建议（1节）
6. 收口判断句 + 互动问句

**加分项**：文章顶部加目录（列出所有H2）；阅读时间估算（如"约3500字，读完9分钟"）；实质配图必备（场景插画加原创信息图，标注假设与口径）；合规与风险提醒用一句口语融进正文（如"授权要一项一项谈"），不单独成段。

**末尾禁放清单**（2026-10-27定）：
- 不写"阅读来源"章节、文末说明、免责声明块、AI辅助声明块；用户明确要求时除外
- 正文、页眉、落款都不出现品牌名"巨人之上"；品牌只存在于账号本身
- 不写新华社、经济参考报等官媒署名式交代，不写《……办法》等法规公文名

## HTML 排版（基于 templates/wechat_template.html）

**配色Token**：
```
--bg: #FAF9F5        /* 页面背景，米白 */
--fg: #141413        /* 正文 */
--muted: #87867F     /* 注释/说明文字 */
--border: #E3DACC
--accent: #C96442    /* 砖红，强调色 */
--accent-d: #B04A3F  /* 深砖红，加粗正文 */
```

**排版规则**：
- 字体：标题 Noto Serif SC（宋体感），正文 Noto Sans SC
- 最大宽度 720px 居中
- Hero区：eyebrow（栏目+日期）+ H1大标题 + lead副标题
- H2节标题：左侧 `.sec-num` 编号（01/02/03…），下方分割线
- 重点金句：`.pull` 卡片（圆角白底 + 左侧砖红竖条）
- 收口：`.close` 深色反白块（#141413底、米白字、砖红高亮词）
- 页脚：默认不放来源、落款与品牌块；结尾直接进互动问句
- 图片：`<figure>` + `<figcaption>`，配图规范见 images.md
- 动效：元素 `animation: rise .5s ease both`（向上淡入），兼容 prefers-reduced-motion

## 交付物（写入输出目录）

1. `公众号_[主题]_终版.md`（正文Markdown）
2. `公众号_[主题]_终版.html`（完整自包含HTML，图片用相对路径或内联）
3. ws 环境起本地 HTTP 服务并经 open_preview 给 `http://localhost` 预览链接；其他环境降级 `file:///`
