# 小红书笔记创作规范（巨人之上）

## 定位

将公众号深度文章降维为小红书风格：保留核心干货，去掉论证过程，强化视觉钩子和即时行动感。

## 文案撰写（`小红书文案.md`）

**字数限制**：正文≤1000字（含换行空格，用 `len(text)` 检查而非目测）

| 维度 | 规则 |
|------|------|
| 开篇 | 第一句戳痛点或讲自己踩过的坑，不讲背景 |
| 节奏 | 短句为主，每段3-5行，用📷图X指引卡片图 |
| URL | 每个链接独占一行，不堆在一起 |
| 结尾 | 金句 + 互动问句（"你还有什么……？评论区聊聊👇"） |
| 禁止 | 论文式推导、长段落、营销腔 |

**交付包结构**：
```
## 一、发布版正文（直接全选复制，≤1000字）
[正文，含📷图X指引、URL每行一个、标签]

## 二、标题（20字内，二选一）
[标题1]
[标题2]

## 三、配图清单（按顺序上传）
| 顺序 | 文件 | 内容 |

## 四、备查信息（不发布）
[数据来源等]
```

**标签**：6-8个，前3个精准（话题相关），后3-5个泛流量词。

## 卡片图制作

**规格**：1080×1440px（3:4），`device_scale_factor=2` 截图（实际2160×2880）

**模块数量**：通常4-5张
- 封面（01）：标题钩子 + 核心卖点3条
- 内容卡片（02-04）：每张一个主题，文字+图标/emoji
- 收口卡片（末张）：金句 + 信息汇总

**设计规范**（与公众号一致）：
- 底色：渐变背景（深色系或浅米色系，不用纯白）
- 字体层级：主标题 52-60px / 副标题 32-36px / 正文 26-28px / 说明 22px
- 强调色：砖红 #C96442 或主题色
- 内容不超出卡片高度（截图前检测 scrollHeight，溢出需压缩字号或拆分卡片）
- URL样式：等宽字体，轻描边圆角框

**技术流程**：
1. 写单文件 HTML 到系统 temp（所有卡片分块布局，各块带 `#card1..#cardN` id）
2. 跑 `scripts/xhs_screenshot.py --html <temp路径> --out <输出目录> --count N`
3. 脚本自动检测 scrollHeight 溢出并告警
4. PNG 输出到输出目录，命名 `01_封面.png`、`02_xxx.png`…

## 踩坑记录

- 卡片内容溢出1440px会被 `overflow:hidden` 裁掉，截图前必须检测 scrollHeight
- 小红书正文字数计算含换行和空格
- URL不能堆在一起，每行一个才符合小红书排版
- 标题超20字会被截断
- 同一账号多网页端登录会互踢，发布时提醒用户
