写稿

把创作简报发给你配置的模型（DeepSeek / 通义 / Kimi / OpenAI 等任意 OpenAI 兼容接口），一次写出公众号 + 小红书双稿。

在本机后台运行 codex exec，用你自己的 Codex 登录写稿，不需要额外 API Key。过程日志实时显示在下方。

复制简报给任意 AI（网页版也行），把它的完整回复贴回来。
