# 复杂系统专家视角包

「一稿」的写作视角。界面上显示为「复杂系统专家」，内核使用 `shifenxiyin-perspective` skill（v1.6.1）。

- `SKILL.md`：框架正文。写稿时只注入其中「输出规范 / 核心心智模型 / 决策启发式 / 表达风格」四节
- `03-expression-dna.md`、`05-heuristics-cases.md`：表达风格与启发式案例补充
- `macro_latest.py`：可选的宏观数据读数工具。需要在「设置」里填 `ATTRACTOR_API_KEY`，不填就跳过

升级内核：把新版 skill 的同名文件覆盖到本目录即可。本机 hermes skills 目录里如果装了更新的版本，产品会自动优先用新版。
